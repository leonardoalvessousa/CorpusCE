# CorpusCE
CorpusCE - Corpus Linguístico e Cultural do Ceará Descrição do Projeto  O CorpusCE é uma iniciativa de dados abertos voltada para a coleta, organização, preservação e disponibilização de conhecimento sobre o estado do Ceará para aplicações de Inteligência Artificial, Processamento de Linguagem Natural (PLN) e pesquisa acadêmica.
